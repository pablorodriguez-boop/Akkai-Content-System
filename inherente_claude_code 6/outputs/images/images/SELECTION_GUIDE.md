# Guía de selección para el sistema de diseño

Usa esta lógica antes de escoger una imagen:

## 1. ¿Qué debe lograr la pieza?
- **Vender ahora** → conversión, CTA, oferta, catálogo.
- **Crear deseo** → hero, ambiente, editorial, lifestyle.
- **Explicar** → educativo, demostración, proceso.
- **Dar confianza** → prueba social, UGC, resultados, equipo/founder.
- **Mostrar contexto** → espacios, eventos, servicio/experiencia.
- **Apoyar composición** → texturas, fondos, extras.

## 2. ¿Qué debe dominar visualmente?
- El producto → `01`, `06`, `07`, `27`.
- La persona → `04`, `05`, `13`.
- La atmósfera → `03`, `15`, `16`, `18`.
- La evidencia → `10`, `11`, `12`, `29`.
- La acción/proceso → `08`, `09`, `19`, `28`.

## 3. Jerarquía sugerida
Cuando haya varias opciones igualmente válidas, prioriza:
1. Imagen aprobada y actual.
2. Imagen alineada con el objetivo exacto de la pieza.
3. Imagen con composición adecuada al formato final.
4. Imagen coherente con la identidad visual de la marca.
5. Imagen con suficiente espacio negativo para copy, cuando aplique.

## 4. Evitar
- Usar `21_extras_broll_stills/` como primera opción si existe una categoría específica.
- Usar imágenes de `98_no_usar/`.
- Confundir `30_referencias_aprobadas/` con entregables finales; ese folder sirve como benchmark visual interno aprobado.
