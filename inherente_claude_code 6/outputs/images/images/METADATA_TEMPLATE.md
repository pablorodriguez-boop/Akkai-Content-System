# Metadata opcional por imagen

Cuando una imagen sea especialmente importante, puede acompañarse de un archivo `.md` o `.json` con el mismo nombre base.

Campos sugeridos:
- `subject`: sujeto principal.
- `category`: categoría principal.
- `secondary_tags`: etiquetas secundarias.
- `campaign`: campaña relacionada.
- `product_or_service`: producto o servicio.
- `orientation`: vertical, horizontal, square, wide.
- `shot_type`: closeup, medium, full, detail, overhead, etc.
- `mood`: atmósfera/emoción.
- `best_for`: usos recomendados.
- `avoid_for`: usos no recomendados.
- `copy_space`: left, right, top, bottom, none.
- `status`: approved, alt, seasonal, archived.
- `date_created`: fecha.
- `notes`: observaciones.
