# Brand Assets

Aqui van los archivos visuales y materiales oficiales de la marca que sirven como fuente de produccion.

## Ejemplos

- logos y variantes;
- iconos;
- packaging;
- packshots oficiales;
- menu o catalogo visual;
- screenshots de aplicaciones reales de marca;
- elementos graficos;
- fotos oficiales aprobadas;
- plantillas existentes.

Si el archivo explica reglas de marca, tambien puede existir una copia o documento equivalente en `brand_context/design/`. Aqui se prioriza el asset utilizable en produccion.
