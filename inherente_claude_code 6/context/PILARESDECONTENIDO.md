# PILARESDECONTENIDO.md — Territorios narrativos derivados de estrategia

> Los pilares no son “temas que podemos hablar”. Son territorios repetibles que conectan deseo del público, posicionamiento, promesa, historia y resultado de negocio.

## 1. Regla para crear un pilar

Un pilar solo existe si puede completar esta fórmula:

```text
TENSIÓN / DESEO DEL ICP
+ VERDAD O PUNTO DE VISTA DE MARCA
+ PROMESA / TRANSFORMACIÓN
+ PRUEBA O EXPERIENCIA
= TERRITORIO DE CONTENIDO
```

Si no conecta al menos esos cuatro elementos, es un tema suelto, no un pilar.

## 5. Test anti-genericidad

Antes de aprobar un pilar, preguntar:

- ¿Podría un competidor publicar exactamente lo mismo sin cambiar una palabra?
- ¿Está conectado a una tensión real del ICP?
- ¿Refuerza una posición específica?
- ¿Acerca al cliente al final feliz?
- ¿Existe una prueba, experiencia o punto de vista que le dé autoridad?
- ¿Puede sostener múltiples formatos sin repetirse?

Si la primera respuesta es “sí” o alguna de las siguientes es “no”, el pilar se redefine.
