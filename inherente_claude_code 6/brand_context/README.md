# Brand Context

Este folder contiene la verdad especifica de la marca activa. Cambia para cada cliente o marca; la metodologia de `context/` no cambia.

## Regla importante

Los `README.md` dentro de este folder son solo guias de carga. No son hechos de la marca y Claude no debe usarlos como evidencia del cliente.

## Como usarlo

1. Cargar documentos reales de la marca en el subfolder correcto.
2. Mantener separado lo estrategico de los assets visuales.
3. No inventar informacion para llenar huecos.
4. Si falta algo, marcarlo como `POR DEFINIR` o `HIPOTESIS`.

## Subfolders

- `brand/` - definicion estrategica general de la marca.
- `icp/` - publico, segmentos, entrevistas y psicografia.
- `offer/` - productos, servicios, precios, claims y pruebas.
- `content/` - contenido historico, canales, ejemplos y aprendizajes.
- `design/` - sistema visual y reglas creativas.
- `calendar/` - lanzamientos, promociones y prioridades por fecha.
- `analytics/` - resultados, exports y aprendizajes de performance.
- `community/` - conversaciones, FAQs, CRM, comunidad y pertenencia.
- `founder/` - historia, autoridad y voz del fundador cuando aplique.
- `competitors/` - competidores, alternativas y mapas de posicionamiento.
- `research/` - investigacion de mercado, cultura y hallazgos adicionales.
