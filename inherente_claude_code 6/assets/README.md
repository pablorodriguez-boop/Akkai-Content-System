# Assets

Material fuente aprobado para producción.

- `brand/` — logos, iconos, packshots oficiales y elementos de identidad.
- `originals/` — fotos reales del producto, persona, espacio u objeto cuya identidad debe conservarse.
- `references/` — fotos que muestran cómo queremos que se vea la nueva ejecución: composición, luz, cámara, atmósfera, styling, fondo o dirección de arte.
- `video/` — clips fuente.
- `audio/` — música, voz, SFX o referencias sonoras.

## Regla original vs. referencia

`originals/` responde **qué debe seguir siendo lo mismo**.

`references/` responde **cómo queremos que se vea la nueva imagen**.

Un output generado nunca se guarda como original automáticamente. Los entregables van a `outputs/`.
