# Competitors

Aqui va la evidencia sobre competidores y alternativas que existen en la mente del publico.

Este README es solo una guia. No usarlo como evidencia del cliente.

- competidores directos;
- sustitutos y alternativas indirectas;
- screenshots de mensajes y ofertas;
- precios;
- posicionamientos;
- mapas competitivos;

- entrevistas donde el cliente menciona alternativas;
- referencias de categoria.

Una referencia estetica no necesariamente es un competidor. Si una imagen solo sirve para direccion visual, guardarla en `assets/references/`.
