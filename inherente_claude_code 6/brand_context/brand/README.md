# Brand

Aqui va la definicion estrategica especifica de ESTA marca.

Este README es solo una guia. No representa informacion real de la marca.

## Que puede ir aqui

- overview de la empresa y categoria;
- historia y contexto del negocio;
- posicionamiento aprobado;
- promesa de marca;
- narrativa: heroe, objetivo, desafios, villanos y transformacion;
- personalidad y atributo que la marca transfiere al cliente;
- valores y creencias;
- voz y tono;
- pruebas que sostienen el posicionamiento;
- restricciones o lineamientos importantes.

## Archivos sugeridos

- `BRAND_OVERVIEW.md`
- `POSITIONING.md`
- `PROMISE.md`
- `NARRATIVE.md`
- `PERSONALITY.md`
- `VALUES.md`
- `VOICE.md`
- `PROOF.md`

Los archivos sugeridos no son obligatorios. Se pueden subir PDFs, notas, decks u otros documentos reales del cliente.
