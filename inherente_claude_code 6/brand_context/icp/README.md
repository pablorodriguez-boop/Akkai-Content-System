# ICP

Aqui va la evidencia especifica del publico de la marca.

Este README es solo una guia. No usarlo como evidencia del cliente.

## Que puede ir aqui

- perfiles de cliente ideal;
- segmentos prioritarios;
- entrevistas y transcripciones;
- encuestas;
- reseñas y comentarios;
- deseos, miedos, frustraciones y aspiraciones;
- habitos, valores y conversaciones;
- como el publico se ve, como quiere ser visto y como cree que lo ve el mundo;
- objeciones y lenguaje literal del cliente.

Priorizar evidencia real sobre descripciones genericas de buyer persona.
