# Outputs

Entregables producidos por el sistema.

- `ads/` — anuncios y variaciones publicitarias.
- `organic/` — contenido orgánico.
- `campaigns/` — campañas y paquetes de campaña.
- `images/` — imágenes generadas o finales, incluyendo el flujo Higgsfield original + referencia.
- `video/` — videos o motion finales cuando corresponda.

Los outputs son resultados. No usar este folder para modificar la metodología de `context/`.

Los aprendizajes específicos de una marca deben documentarse en `brand_context/analytics/` o en el repositorio de conocimiento específico de esa marca.
