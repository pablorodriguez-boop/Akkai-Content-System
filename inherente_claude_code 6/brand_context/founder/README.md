# Founder

Aqui va el contexto del fundador cuando su figura sea un ingrediente relevante de la marca.

Este README es solo una guia. No usarlo como evidencia del cliente.

## Que puede ir aqui

- biografia;
- historia de origen;
- track record;
- credenciales;
- opiniones y puntos de vista;
- historias personales utilizables;
- limites de exposicion;
- tono y voz del fundador;
- fotos, entrevistas o transcripciones de referencia textual.

La figura del fundador puede aportar autoridad y humanidad, pero el cliente sigue siendo el heroe de la narrativa.
