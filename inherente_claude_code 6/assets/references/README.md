# References

Aqui van imagenes que representan la direccion visual deseada para una nueva ejecucion.

## Funcion

Responde: **como queremos que se vea**.

Se pueden usar para extraer:
- composicion;
- encuadre;
- angulo de camara;
- sensacion de lente;
- iluminacion y sombras;
- profundidad de campo;
- fondo;
- styling;
- textura;
- atmosfera;
- color grading;
- direccion de arte.

La referencia no define la identidad del producto. En el flujo de Higgsfield, la identidad viene de `assets/originals/` y la referencia aporta direccion visual.
