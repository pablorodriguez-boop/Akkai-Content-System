# Calendar

Aqui va el contexto temporal y comercial de la marca.

Este README es solo una guia. No usarlo como evidencia del cliente.

## Que puede ir aqui

- lanzamientos;
- promociones;
- eventos;
- temporadas;
- fechas comerciales;
- deadlines;
- prioridades del mes;
- ventanas de campaña;
- frecuencia de publicacion acordada;
- dependencias entre contenido, ads y ventas.

El calendario cambia por marca y por periodo. No modificar `context/CALENDAR.md` para acomodar una campaña puntual.
