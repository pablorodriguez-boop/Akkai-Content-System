# Skills

Cada subfolder representa una acción operativa.

Todos los skills deben separar dos capas:

- `context/` = metodología reutilizable e inmutable.
- `brand_context/` = hechos y restricciones de la marca activa.

Skills previstos:

- `create-ad/`
- `carousel/`
- `stories/`
- `campaign/`
- `repurpose/`
- `translate/`
- `reverse-engineering/`
- `generate-images/`

`generate-images/` usa el modelo **original + referencia + contexto de marca → nueva imagen**, ejecutado mediante Higgsfield Cinematic Cameras Generate.
