# Design

Aqui va el sistema visual especifico de la marca y sus decisiones creativas aprobadas.

Este README es solo una guia. No usarlo como evidencia del cliente.

## Que puede ir aqui

- brand guidelines;
- paleta y codigos de color;
- tipografias aprobadas;
- reglas de composicion;
- fotografia y direccion de arte;
- estilo de ilustracion;
- motion y video;
- iconografia;
- uso de logo;
- ejemplos de piezas aprobadas;
- cosas que visualmente se deben evitar.

Los archivos binarios como logos, fotos, packshots o videos fuente deben vivir en `assets/`.
