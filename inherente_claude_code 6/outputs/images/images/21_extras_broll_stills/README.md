# Extras y B-roll stills

Imágenes secundarias de apoyo: detalles ambientales, manos, objetos, momentos de transición o tomas útiles que no encajan mejor en otra categoría.

## Qué debe guardar este folder
Solo imágenes finales o listas para diseño que correspondan principalmente a esta función.

## Regla para el sistema de diseño
Prioriza este folder cuando la intención visual de la pieza coincida directamente con esta categoría.
