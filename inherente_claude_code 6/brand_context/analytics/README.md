# Analytics

Aqui van los datos y aprendizajes reales de performance de la marca.

Este README es solo una guia. No usarlo como evidencia del cliente.

## Que puede ir aqui

- exports de Meta, TikTok, YouTube, LinkedIn u otras plataformas;
- GA o analytics web;
- CRM;
- leads y conversiones;
- ingresos atribuidos;
- performance por pieza, formato y hook;
- reportes semanales o mensuales;
- hipotesis validadas o descartadas;
- aprendizajes documentados.

Separar siempre inputs de media de outputs de negocio. No convertir un aprendizaje de una marca en regla global de `context/`.
