# ANALYTICS.md — Creatividad convertida en sistema

> Este archivo es memoria de aprendizaje. Su trabajo es explicar **por qué** algo funcionó o falló y convertirlo en una regla operativa.

## 1. Dos visiones obligatorias

### INPUT / media y marketing
- alcance;
- engagement;
- retención;
- seguidores generados;
- clics en bio;
- clics en stories/links;
- respuestas;
- visitas;
- reproducciones calificadas.

### OUTPUT / negocio
- leads;
- leads calificados;
- oportunidades;
- conversiones;
- ingresos;
- costo;
- señales de comunidad/pertenencia.

No reportar inputs sin mostrar su relación con outputs cuando exista trazabilidad.

## 3. Tres tipos de hipótesis

### MEJORA
Qué modificar para elevar desempeño de algo que ya muestra señal.

### EXCLUSIÓN
Qué dejar de hacer porque no funciona, no aporta a marca o no genera aprendizaje útil.

### INNOVACIÓN
Qué probar de nuevo a partir de patrones observados.
